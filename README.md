# ☕ Java Lab Programs – MCA Semester 2

This repository contains Java programs developed as part of the **MCA Semester 2 Lab (OOP & Advanced Java Concepts)**.

---

## 📂 Repository Structure

```
src/
├── (Java program files)
```

All programs are organized inside the `src` folder.

---

## 📚 Syllabus Covered

### 🔹 Module I: OOP Concepts

* Procedural vs Object-Oriented Programming
* Classes and Objects
* Constructors
* Access Modifiers
* Method Overloading
* Recursion

---

### 🔹 Module II: Inheritance & Arrays

* Types of Inheritance (Single, Multilevel)
* Method Overriding
* `this` and `super` keywords
* Interfaces
* Arrays (1D & 2D)
* String handling

---

### 🔹 Module III: Exception Handling, I/O & Threads

* Exception Handling (try-catch, throw, throws)
* Custom Exceptions
* File Handling (Byte & Character Streams)
* Multithreading and Synchronization

---

### 🔹 Module IV: GUI Programming (AWT & Swing)

* AWT vs Swing
* Components: JFrame, JButton, JLabel, JTextField
* Layout Managers (Flow, Border, Grid)
* Event Handling

---

### 🔹 Module V: JDBC

* JDBC Architecture
* Database Connectivity
* CRUD Operations (Insert, Update, Delete, Select)

---

## ⚙️ How to Run the Programs

### 🔹 Using Command Line

1. Navigate to the `src` folder:

   ```
   cd src
   ```
2. Compile the program:

   ```
   javac FileName.java
   ```
3. Run the program:

   ```
   java FileName
   ```

---

### 🔹 Using Eclipse IDE

1. Import the project into Eclipse
2. Open the `src` folder
3. Run any `.java` file as **Java Application**
